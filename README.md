# viseu. — portal local independente

Primeira fundação V31. Interface editorial responsiva em português de Portugal. Abre index.html num servidor estático. Pesquisa, 25 freguesias de referência, ligações oficiais, cabaz manual e importação privada de dados. Não é uma versão de produção; eventos agregados e preços automáticos aguardam autorização e validação. Marca provisória. Dados de pesquisa restritos e segredos não incluídos.
